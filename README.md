# Cadastro de Produto

Projeto em Java desenvolvido com o objetivo de simular o cadastro de produtos, aplicando conceitos de Programação Orientada a Objetos (POO).

## 📌 Funcionalidades

* Cadastro de produtos
* Armazenamento de nome e preço
* Controle de quantidade total (atributo estático)
* Exibição dos dados cadastrados

## 🧠 Conceitos aplicados

* Encapsulamento
* Atributos privados
* Métodos getters e setters
* Validação de dados
* Uso de atributo estático
* Construtores

## 🛠 Tecnologias utilizadas

* Java
* Eclipse IDE

## ▶️ Como executar

1. Abra o projeto no Eclipse
2. Execute a classe `Main`
3. Visualize os dados no console
