# 📚 Biblioteca Digital

## 📌 Sobre o projeto

A Biblioteca Digital é uma aplicação desenvolvida em **Java com Java Swing**, criada para praticar conceitos de Programação Orientada a Objetos (POO) e desenvolvimento de interfaces gráficas.

O sistema permite gerenciar livros por meio de uma interface simples e intuitiva.

## 🚀 Funcionalidades

* ✅ Cadastrar livros.
* ✅ Listar livros cadastrados.
* ✅ Editar livros.
* ✅ Excluir livros.
* ✅ Interagir com a aplicação por meio de uma interface gráfica.

## 🛠️ Tecnologias utilizadas

* Java
* Java Swing
* ArrayList
* Programação Orientada a Objetos (POO)
* Eclipse IDE

## 🎯 Objetivos de aprendizagem

Este projeto foi desenvolvido para praticar:

* Criação de interfaces gráficas com Java Swing.
* Manipulação de listas utilizando ArrayList.
* Organização e reutilização de código.
* Implementação de operações de gerenciamento de dados.
* Aplicação de conceitos de orientação a objetos.
